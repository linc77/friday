# Provider 配置与任务实例

「设置 → Providers」管理当前主机的任务执行器。Friday 主会话的 API 连接独立于这些执行器。

| 执行器 | 原生连接 |
| --- | --- |
| Codex | Codex App Server |
| Claude | 官方 Agent SDK 与主机上的 Claude Code |
| Pi | Pi RPC |
| Grok | 原生 ACP 与 Grok 扩展 |
| Cursor | 官方 Cursor SDK |
| Muse Code | Muse 原生 SDK |
| OpenCode | 原生 HTTP SDK，兼容 v1／v2 |
| ACP Registry | 所选 Registry 工具或本地 ACP 可执行文件 |
| Antigravity | 原生 ACP 与独立运行配置 |

工具检测、模型目录、认证状态与实际执行是不同的能力。发现已安装程序或添加模型 ID，不代表账号已登录、模型可用或支持所有历史操作。未接入的其他工具仍可显示安装检测结果。

## 多实例

主机可以为同一种执行器添加多个实例，配置实例 ID、显示名称、颜色和启用状态，再分别配置工具、账号目录与环境变量。实例 ID 长度最多 64，使用字母开头及字母、数字、下划线或短横线。

默认实例 ID 等于执行器名称，例如 `codex`。旧任务没有实例字段时仍关联该默认实例，不迁移或复制其原有配置。新增实例的配置保存在主机数据目录的独立私有子目录，目录清单文件以 `0600` 权限原子写入。不同实例可以显式指向同一个原生账号目录；实例不会凭空创建新的供应商账号。

任务在执行前持久化实例 ID。续聊、队列、工作区命令、额度读取、分叉、子会话及历史操作沿用这个实例；实例不匹配或缺失时明确拒绝，不回退到另一账号。运行中实例不能停用。仍关联任务或未确定消费结果的实例不能移除，移除后的 ID 保留，避免旧请求指向新账号。

已配对设备可读取实例和可用模型。新增实例、修改工具配置、安装工具及交互式认证需要主机身份。环境变量和原生凭据不会回传给客户端。

## 认证

- Codex 可从页面启动 ChatGPT 登录，也可使用已有 `CODEX_HOME`、独立账号目录及网关配置。
- Cursor 使用原生 SDK 登录或 `CURSOR_API_KEY`。
- Claude、Pi、Grok、Muse、OpenCode 使用各工具的原生账号配置；设置页给出对应入口。Claude 支持 `CLAUDE_CONFIG_DIR` 与原生环境变量。
- Registry 读取所选工具真实声明的认证方式：工具内部认证、交互式终端、环境变量认证。环境变量方式只验证已配置凭据，不额外调用登录 RPC。

终端认证复用原生终端组件，显示真实 PTY 输出，支持输入和窗口尺寸。取消会关闭本流程拥有的进程。浏览器认证先显示工具请求的 URL，用户明确同意后才打开；过期流程或交互回包不能操作新流程。凭据页面链接也由用户点击打开。

认证状态由常驻服务持有，可通过实时订阅恢复显示；离开设置页不自动取消登录。客户端断线不重发终端输入或浏览器同意。服务重启后不自动重放登录操作。原生登录 ACK 后还需验证新会话，才能标记成功。

同一 Registry 工具可能在多个实例间共享原生登录凭据。共享凭据的认证操作互斥，登录或退出后会使旧凭据绑定失效；旧任务不能悄悄切换账号。认证取消但外部结果不确定时也保留这一约束。

## 模型与原生选项

任务输入框的模型选择器按实例显示模型，支持搜索、收藏、隐藏及排序。设备偏好按服务地址和实例区分。续聊可以更换同一实例的模型，不能切换到另一实例。

「模型选项」根据实际模型目录生成选择项或布尔开关，不为任意自定义 ID 猜测能力：

- Codex：原生推理强度及服务档位；切回 Standard 会显式清除前一档位。
- Cursor：SDK 声明的全部模型参数，包括上下文、Fast 等；界面字段映射回原生参数 ID，布尔值保持含义。
- OpenCode：原生推理变体与已公布的主 Agent；计划模式使用原生 Plan Agent。
- ACP／Antigravity：原生模型、推理和其他已公布的配置项；切换模型后重新验证原生选项。
- Claude：结合实际 SDK 能力与固定 T3 参考的模型配置，支持可用的推理、上下文、Fast、Ultracode 和 Ultrathink 映射。Ultracode 使用原生工作流设置；Ultrathink 使用对应的提示词语义。需要重启的启动设置会恢复原会话，普通模型及可实时更新的设置沿用当前进程。
- Pi、Grok、Muse：使用工具实际声明的推理选项。

选项随任务、队列消息及每次运行记录持久化，并用于续聊、分叉和回退编辑。未知、过期或类型不匹配的选项在原生执行前被拒绝；布尔 `false` 不等同于缺省值。与前台任务分开的文字生成请求不会继承其模型选项。

## 持久化与验证边界

外部会话 ID 在发送任务前写入 Pi Durable 状态。关闭客户端不停止常驻服务中的执行；服务中断后不会自动重放结果不确定的外部操作。

独立文字生成设置当前仍以 Codex／Claude 为范围，其他驱动的独立生成与完整配额矩阵需要继续补齐。Registry 在固定 T3 参考中明确不支持独立文字生成，不能因已支持任务执行而宣称支持。真实供应商账号及 Mac／iPhone 的交互验收也需与协议测试、编译及打包结果分开记录。
