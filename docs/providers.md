# Provider 配置与任务实例

「设置 → Providers」管理当前主机的任务执行器。Friday 主会话的 API 连接独立于这些执行器。

## Friday 主会话的模型供应商

在「Providers → Friday」填写供应商名称、Base URL 与 API Key，点击「获取模型列表」，搜索并选择模型后「验证并保存」。Base URL 使用供应商提供的 OpenAI 兼容 API 根地址，保留 `/v1` 等路径；Friday 从其 `/models` 接口获取目录，通过 `/chat/completions` 调用所选模型。原生 Anthropic、Gemini 等其他协议需要由兼容网关转换。

模型列表支持分页、去重和搜索。请从中选择支持工具调用的对话模型；供应商也可能列出嵌入、图片等模型，目录存在不代表适用于主会话。保存前发送一次简短请求，成功后才启用新配置；失败保留原连接。

现有 DeepSeek Key 和 `FRIDAY_MODEL_ID` 在尚未保存自定义配置时继续生效。保存后的供应商、模型目录、所选模型和密钥在主机数据目录的私有 `model-provider.json` 中以 `0600` 权限原子写入，重启后恢复；同一 Base URL 留空可沿用密钥，更换 URL 必须重新填写。移除密钥保留模型设置。配对设备可以使用当前连接，供应商配置仅由主机修改；Friday 正在处理会话时禁止修改。

## 任务执行器

| 执行器 | 原生连接 |
| --- | --- |
| Codex | Codex App Server |
| Claude | 官方 Agent SDK 与主机上的 Claude Code |
| Pi | Pi RPC |

工具检测、模型目录、认证状态与实际执行是不同的能力。发现已安装程序或添加模型 ID，不代表账号已登录、模型可用或支持所有历史操作。任务执行器只列出 Codex、Claude、Pi。

## 多实例

主机可以为同一种执行器添加多个实例，配置实例 ID、显示名称、颜色和启用状态，再分别配置工具、账号目录与环境变量。实例 ID 长度最多 64，使用字母开头及字母、数字、下划线或短横线。

默认实例 ID 等于执行器名称，例如 `codex`。旧任务没有实例字段时仍关联该默认实例，不迁移或复制其原有配置。新增实例的配置保存在主机数据目录的独立私有子目录，目录清单文件以 `0600` 权限原子写入。不同实例可以显式指向同一个原生账号目录；实例不会凭空创建新的供应商账号。

任务在执行前持久化实例 ID。续聊、队列、工作区命令、额度读取、分叉、子会话及历史操作沿用这个实例；实例不匹配或缺失时明确拒绝，不回退到另一账号。运行中实例不能停用。仍关联任务或未确定消费结果的实例不能移除，移除后的 ID 保留，避免旧请求指向新账号。

已配对设备可读取实例和可用模型。新增实例、修改工具配置及 Codex 登录需要主机身份。环境变量和原生凭据不会回传给客户端。

## 认证

- Codex 可从页面启动 ChatGPT 登录，也可使用已有 `CODEX_HOME`、独立账号目录及网关配置。
- Claude、Pi 使用各工具的原生账号配置。Claude 支持 `CLAUDE_CONFIG_DIR` 与原生环境变量。

## 模型与原生选项

任务输入框的模型选择器按实例显示模型，支持搜索、收藏、隐藏及排序。设备偏好按服务地址和实例区分。续聊可以更换同一实例的模型，不能切换到另一实例。

模型参数根据实际模型目录校验，不为任意自定义 ID 猜测能力。输入框仅保留模型与推理强度选择，已移除“模型选项”菜单：

- Codex：原生推理强度及服务档位；切回 Standard 会显式清除前一档位。
- Claude：结合实际 SDK 能力与固定 T3 参考的模型配置，支持可用的推理、上下文、Fast、Ultracode 和 Ultrathink 映射。Ultracode 使用原生工作流设置；Ultrathink 使用对应的提示词语义。需要重启的启动设置会恢复原会话，普通模型及可实时更新的设置沿用当前进程。
- Pi：使用工具实际声明的推理选项。

选项随任务、队列消息及每次运行记录持久化，并用于续聊、分叉和回退编辑。未知、过期或类型不匹配的选项在原生执行前被拒绝；布尔 `false` 不等同于缺省值。与前台任务分开的文字生成请求不会继承其模型选项。

## 独立文字生成

任务标题和 Git 说明可选择 Codex、Claude、Pi 的具体实例与模型。调查式 Guide 只提供固定 T3 支持的 Codex／Claude。

生成请求不续接前台会话，不继承前台账号绑定或模型选项。Pi 禁用工具与扩展，Muse 禁用 Shell／写文件，OpenCode 拒绝全部工具，Grok 使用默认权限并拒绝交互，Antigravity 使用原生计划模式并关闭客户端文件访问。Cursor 使用临时空目录、原生沙箱和计划模式，完成后清理目录；存在自定义 `~/.cursor/sandbox.json` 时拒绝该独立生成路径。

## 账号额度

额度面板保留 Codex／Claude 的原生接口。百分比、窗口与重置时间采用供应商数据；没有数据与用量为零分别显示。Pi 不声明尚未接入的账号配额。

## 历史分叉与回退

Codex、Claude、Pi 提供各自的原生历史操作。Pi 保存真实会话树游标，只沿活动分支核对；分叉及回退创建独立文件，保留原会话。文件恢复统一由 Friday 已有的检查点阶段处理。

保留的三个执行器可以从可见历史建立独立会话。旧 Pi 记录缺少可靠游标时提供可见历史路径。原生操作结果不确定时只核对已保存的候选，不重复创建或回退。

## 原生子会话与后台工作

Codex、Claude、Pi 的原生子会话、后台工作及后续回复沿用各自已实现的能力。子对话保存父实例、原生连接和父轮次身份，结果与消息可在重启后查看；审批沿原始请求返回。原生观察任务由 Pi Durable 持久化，不重发提示词来恢复不确定的外部执行。

## 已移除的执行器与旧任务

OpenCode、Grok、Muse、Cursor、Antigravity 和 ACP Registry 的执行接入、配置入口与专属 SDK 已移除。历史任务、消息、结果、原生会话标识和未发送队列保留；不把旧任务自动映射到其他 Agent。旧实例记录和本机私有配置不主动删除，实例标识不能重新绑定到其他 Agent。

这些旧任务可继续查看，但不能续聊、恢复队列或创建新的原生执行。需要继续工作时，请使用 Codex、Claude 或 Pi 新建任务。旧队列在重启后保持暂停。此变更不改变 Friday 主会话的模型 API、Pi Durable 或多端 HTTPS 连接。
