# 图标与动效规范

本文记录用户确认的 Friday 图标偏好，适用于产品界面的导航、按钮、空白页和状态图标。后续新增与修改应延续这些约定；用户提出新的具体要求时，更新本文对应条目。

## 图标风格

- 统一使用 Apple SF Symbols，通过系统图标 API 调用，不使用 emoji、第三方图标库或自绘 SVG、位图替代界面图标。
- 默认采用单色、细线或常规字重；同一层级保持一致的尺寸与视觉重量。
- 同一功能在不同入口使用一致的符号语义，不因为切换页面而换成另一套图标。

## 品牌 Logo

- Friday 的品牌标识使用 **V**，表示罗马数字 **5**，呼应 Friday／周五。
- 采用纯黑底、柔和灰白（`#E6E6E6`）的几何字形：直线斜笔画、平直端头、尖角底部；左笔画镂空，右笔画实心。参考用户提供的 X 图标风格，避免胶囊端头与过度圆润的字形。
- 品牌 Logo 使用 SVG 多边形母版：白色外轮廓、黑色镂空的边缘均为直线，相同方向的边缘严格平行，每条笔画与镂空保持固定宽度。从矢量路径直接按各尺寸导出 macOS、iOS 与应用内资源，避免图片生成或描摹造成边缘弯曲、笔画渐变宽。
- 上述 SF Symbols 约定适用于功能图标。母版与导出规则见 [品牌资源说明](../assets/brand/README.md)。

## 动效原则

- 所有产品界面图标应提供与交互或真实状态对应的动效反馈，覆盖导航、操作与状态变化。
- 图标动效默认采用 **Draw On → Whole Symbol → Once**：整个符号沿笔画绘制一次。使用原生系统符号转场，保留 SF Symbols 的笔画表现。
- 左下角设置齿轮按钮是已确认的例外：点击时使用原生 **Rotate → Clockwise → Whole Symbol → Once**，整个齿轮顺时针旋转一次，不叠加 Draw On，不在悬浮或选中期间循环旋转。
- 除设置齿轮外，不混用 Bounce、Wiggle、Rotate、Pulse 和 Breathe 等图标动效。
- 所有按钮（含模块导航、设置导航与主题选项）只在点击或键盘激活时播放一次图标动效；鼠标悬浮不触发绘制、缩放或渐变动画。悬浮时可以即时显示静态高亮与名称提示。
- 重复点击当前选中项也播放一次；程序切换选中项不触发按钮动效。状态图标仍随真实状态变化反馈。
- 默认单次播放，不在静止状态循环，不因普通视图重建、页面打开或刷新而无故重播。历史任务不得重播完成动画。
- 任务进入运行、完成、失败等新状态时绘制一次；保持运行期间不循环播放，用图标与文字持续表达状态。
- 动效结束后图标保持完整、可辨认，不能停在隐藏或未绘制完的状态。动画不得改变布局、点击区域或抢走焦点。

| 模块 | SF Symbol | 动效 | 播放方式 |
| --- | --- | --- | --- |
| 对话 | `ellipsis.message` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 想法 | `scribble` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 任务 | `checklist.unchecked` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 项目 | `folder` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 记忆 | `sparkles` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |

- 原“记录／对话记录”模块统一命名为“任务”，相关标题、导航与辅助说明保持一致。
- 发送、导出、添加、展开详情等操作，以及空白页、错误提示和连接状态图标，同样使用上述 Draw On 规则。

## 桌面窗口布局

- 左侧栏宽度为 **60 pt**，只展示图标，悬浮显示模块名称。
- 侧栏图标统一为 **17 pt**，按钮区域为 **32 × 32 pt**，圆角为 **8 pt**。
- 侧栏按钮不绘制焦点描边；键盘焦点通过图标前景色提示，选中项用淡灰背景区分。
- 原生红绿灯按钮尺寸为 **13.2 pt**、间距为 **4 pt**，整组居中对齐侧栏。
- 内容区域延伸到窗口顶部，顶部、右侧、底部边距统一为 **5 pt**；红绿灯下方为侧栏导航区域。

## 无障碍与兼容

- 遵循系统“减少动态效果”设置，启用时保留清晰的静态图标和选中状态。
- 应用处于后台时不触发交互动画；返回前台不补播已发生的反馈。
- 新符号和动效必须检查 SDK 与系统版本，并为项目最低支持版本提供降级。旧系统缺少符号时使用语义相近的 SF Symbol。
- Draw On 不可用时保留静态 SF Symbol，不回退到其他类型的图标动效。降级同样遵循无障碍设置。
- 设置齿轮的原生 Rotate 需要 macOS 15 / iOS 18 或以上；不支持时保留静态图标，同样遵循减少动态效果与后台停止规则。
- 平台控件无法呈现某种动效时，明确说明限制，不能把静态图标报告为已经验证的动画。
- 系统管理的原生标签栏保留系统图标呈现；不能直接套用自定义图标转场，也不把它计为已完成 Draw On 验证。

## 验证与维护

- 图标改动按项目测试预算做最小验证：差异检查、必要的原生编译或相关 UI 检查，以及一次真实窗口检查。
- 检查触发方式、单次播放、动画结束后的完整图标和页面切换，以及减少动态效果和后台停止；历史状态不应在打开或刷新时重播。
- 编译通过、静态截图与实际观察到动画是不同的验证结果，交付时如实说明。
- 本文保存偏好、符号与动效约定，不复制实现源码；项目 `AGENTS.md` 只保留本文链接，避免规则重复和漂移。
