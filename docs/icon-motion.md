# 图标与动效规范

本文记录用户确认的 Friday 图标偏好，适用于产品界面的导航、按钮、空白页和状态图标。后续新增与修改应延续这些约定；用户提出新的具体要求时，更新本文对应条目。

## 图标风格

- 功能图标默认使用 Apple SF Symbols，通过系统图标 API 调用，不使用 emoji、自绘 SVG 或位图替代。Worktree 使用下方已确认的 Codicons 例外；Agent 选择器中的品牌标识遵循下方品牌例外。
- 默认采用单色、细线或常规字重；同一层级保持一致的尺寸与视觉重量。
- 同一功能在不同入口使用一致的符号语义，不因为切换页面而换成另一套图标。

### Worktree 图标

- Worktree 使用用户选定的 **VS Code Codicons `worktree`**（横向分出两条箭头），任务列表与 New Worktree 按钮复用同一个 `WorktreeIcon`。原始 SVG、来源、许可与导出说明见 [功能图标资源](../assets/icons/README.md)。
- 使用本地模板图片，单色并继承所在位置的前景色，适配明暗主题。任务列表维持 **11 pt**，新建按钮使用 **14 pt**。
- 此图标保持静态，不套用 SF Symbols 专用 Draw On，也不添加旋转、缩放或循环动画；按钮保留原有选中态与小手光标反馈。Git 分支按钮仍使用 `arrow.triangle.branch`。

## 品牌 Logo

- Friday 的品牌标识使用 **V**，表示罗马数字 **5**，呼应 Friday／周五。
- 采用纯黑底、柔和灰白（`#E6E6E6`）的几何字形：直线斜笔画、平直端头、尖角底部；左笔画镂空，右笔画实心。参考用户提供的 X 图标风格，避免胶囊端头与过度圆润的字形。
- 品牌 Logo 使用 SVG 多边形母版：白色外轮廓、黑色镂空的边缘均为直线，相同方向的边缘严格平行，每条笔画与镂空保持固定宽度。从矢量路径直接按各尺寸导出 macOS、iOS 与应用内资源，避免图片生成或描摹造成边缘弯曲、笔画渐变宽。
- 上述 SF Symbols 约定适用于功能图标。母版与导出规则见 [品牌资源说明](../assets/brand/README.md)。

### Agent 选择器的品牌标识

- 模型选择器的 Agent 筛选、每行 Agent 名称和当前模型按钮使用对应品牌 Logo：Codex 使用 OpenAI 标识，Claude 使用橙色 Claude Spark，与用户提供的参考一致。
- 官方矢量母版与来源保存在 [Agent 品牌资源](../assets/agents/README.md)，随应用打包透明图像，不在运行时联网加载。OpenAI 标识随明暗主题使用单色，Claude 保留官方颜色。
- 品牌 Logo 保持静态，不套用 SF Symbols 专用的 Draw On，也不旋转、变形或在悬浮时动画。筛选通过背景和无障碍选中状态反馈；搜索、收藏、勾选和下拉箭头仍按功能图标规范处理。
- Pi／Grok 尚无已纳入资源库的品牌母版，选择器与设置入口复用通用 `terminal` SF Symbol 和已有交互反馈，不临时绘制品牌图案。

## 动效原则

- 除上述静态图标例外外，所有产品界面图标应提供与交互或真实状态对应的动效反馈，覆盖导航、操作与状态变化。
- 图标动效默认采用 **Draw On → Whole Symbol → Once**：整个符号沿笔画绘制一次。使用原生系统符号转场，保留 SF Symbols 的笔画表现。
- 左下角设置齿轮按钮是已确认的例外：点击时使用原生 **Rotate → Clockwise → Whole Symbol → Once**，整个齿轮顺时针旋转一次，不叠加 Draw On，不在悬浮或选中期间循环旋转。
- 除设置齿轮外，不混用 Bounce、Wiggle、Rotate、Pulse 和 Breathe 等图标动效。
- 所有按钮（含模块导航、设置导航与主题选项）只在点击或键盘激活时播放一次图标动效；鼠标悬浮不触发绘制、缩放或渐变动画。悬浮时可以即时显示静态高亮与名称提示。
- 重复点击当前选中项也播放一次；程序切换选中项不触发按钮动效。状态图标仍随真实状态变化反馈。
- 默认单次播放，不在静止状态循环，不因普通视图重建、页面打开或刷新而无故重播。历史任务不得重播完成动画。
- Snooze 的“已唤醒”确认复用 `clock` 和橙色文字；点击只确认本次唤醒，播放一次 Draw On 并使用小手光标。重复快照和后续输出不重播唤醒动效。
- 后台命令使用 `terminal` 和数量表示，数量变化时绘制一次；不以持续旋转或脉冲表示运行。输入框上方的停止操作使用 `stop`、共用按钮样式和小手光标，点击一次 Draw On，等待回执时禁用重复点击；连接中断用静态文字说明未确认状态。
- 任务进入运行、完成、失败等新状态时绘制一次；保持运行期间不循环播放，用图标与文字持续表达状态。
- 动效结束后图标保持完整、可辨认，不能停在隐藏或未绘制完的状态。动画不得改变布局、点击区域或抢走焦点。

## 光标与点击提示

- macOS 产品界面所有启用的可点击操作统一显示系统小手光标，包括导航、按钮、任务与 Workspace 条目、菜单入口、选择器、开关、链接和推理强度滑条；覆盖完整点击区域，后续新增控件也遵循此规则。
- 复用 `fridayInteractiveCursor()` 和共用按钮样式；无自定义样式的按钮由窗口根视图的默认按钮样式统一处理，保留原生外观与键盘行为。不要把小手光标设置到整页或包含输入框的容器上。
- 禁用控件与静态区域不显示小手；文字编辑保留 I-beam，窗口缩放等系统操作保留原生光标。离开、滚动或移除控件后由系统恢复光标，不使用全局光标推入／弹出。
- macOS 15 及以上使用原生 Pointer Style，macOS 14 使用 AppKit 光标区域。光标变化不触发图标动画。

## 已确认的模块导航约定

| 模块 | SF Symbol | 动效 | 播放方式 |
| --- | --- | --- | --- |
| 对话 | `ellipsis.message` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 想法 | `scribble` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 任务 | `checklist.unchecked` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| Workspace | `folder` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 记忆 | `sparkles` | Draw On，整个符号（`.drawOn.wholeSymbol`） | Once，单次 |
| 设置 | `gear` | Rotate，顺时针、整个符号（`.rotate.clockwise.wholeSymbol`） | Once，点击时单次 |

- 原“记录／对话记录”模块统一命名为“任务”，相关标题、导航与辅助说明保持一致。
- 发送、导出、添加、展开详情等操作，以及空白页、错误提示和连接状态图标，同样使用上述 Draw On 规则。

## 桌面窗口布局

- 左侧栏宽度为 **60 pt**，只展示图标，悬浮显示模块名称。
- 侧栏图标统一为 **17 pt**，按钮区域为 **32 × 32 pt**，圆角为 **8 pt**。
- 侧栏按钮不绘制焦点描边；键盘焦点通过图标前景色提示，选中项用淡灰背景区分。
- 原生红绿灯按钮尺寸为 **13.2 pt**、间距为 **4 pt**，整组居中对齐侧栏。
- 内容区域延伸到窗口顶部，顶部、右侧、底部边距统一为 **5 pt**；红绿灯下方为侧栏导航区域。

## iOS 底部导航

- 输入框和底部菜单放在同一个悬浮面板内；菜单只显示 SF Symbols 图标，不显示文字，无障碍名称保留模块名称。只保留这一排菜单，不再创建系统标签栏。
- 切换到想法、任务、设置及其子页面后，底部菜单仍然保留，可以随时切回对话。
- 图标统一为 **20 pt**、常规字重，按钮点击区域至少 **44 pt**；iOS 26 及以上使用原生 Liquid Glass 面板和选中胶囊，保留水滴般的折射、触摸反馈及切换流动感，不能退化成平面的灰色背景。旧系统或无障碍设置要求时使用静态材质与清晰的选中状态。
- 菜单支持连续左右滑动，玻璃胶囊跟随手指移动，松手后切换到对应模块；保留点按和长按新对话。滑动仅作用于菜单这一排，不占用输入框手势，取消拖动或纵向滑动不切换页面。
- 自定义导航按钮沿用单次 Draw On，设置齿轮沿用单次顺时针 Rotate；程序切换页面不播放点击动效。
- 对话顶部不显示品牌、新对话或设置控件，也不保留其占位；只保留不拦截交互的渐变遮罩，让状态栏下方的滚动内容逐渐淡去。
- 新对话从底部“对话”按钮的长按菜单进入，设置从底部齿轮进入。
- iOS 输入框只在用户点击时聚焦，页面打开和切换回来时不自动弹出键盘。

## 无障碍与兼容

### 任务侧栏 Workspace 切换

- 项目目录在产品界面统一称为 **Workspace**。目录选择和添加入口位于任务侧栏；聊天输入框不再放目录选择。
- Git 工作区中的本地 Task 在输入框工具栏最左侧显示分支按钮，后面依次为模型、推理强度。分支按钮仅显示 `arrow.triangle.branch` 和分支名；输入框中的分支、模型、推理强度按钮均不显示右侧下拉箭头，保留点击打开面板的行为与无障碍名称。分支面板提供搜索与分支切换，不再混入执行位置。点击遵循单次 Draw On。非 Git 工作区的新会话和已有任务均隐藏分支按钮及其分隔线，新会话隐藏执行位置／Worktree 选择，直接在当前目录执行；任务列表也不显示“非 Git 工作区”或 Worktree 标记，保留时间与状态。
- 分支弹窗右上角的刷新使用 **14 pt** `arrow.clockwise`，点击区域固定 **28 × 28 pt**。不绘制系统焦点框，键盘焦点通过图标强调色与淡灰背景表达；悬浮仅即时显示淡灰背景，点击仍为单次 Draw On。
- 新会话的引导文字、执行位置和输入框作为一组在内容区水平、垂直居中；引导文字下方突出展示“当前工作区 / New Worktree”双选项，分别使用 SF Symbol `folder`／Codicons `worktree`。执行位置只在新建时出现，分支选择仍位于输入框最左侧。New Worktree 从所选分支的已提交内容创建独立 `linc/task-…` 分支，不复制未提交改动。非 Git 目录仅允许当前工作区，尚无提交的仓库不可创建 Worktree；选择随各 Workspace 的新任务草稿保留。
- 已有任务读取其实际执行目录的分支，Worktree 任务不改动原 Workspace 目录。空闲时可切换本地分支，继续使用原目录和 Agent 会话；执行中仍显示分支并可查看列表，待任务完成后才能切换。未提交改动、共享该目录的运行或排队任务会阻止切换；切换过程由服务持久执行，不创建新的 Agent 对话，意外中断后不自动重复 Git 操作。
- 根据当前任务模块 1:1 复刻 T3code 的要求，默认使用扁平任务分组，旧版项目树通过设置启用。默认列表保留任务的 Workspace、Agent、分支和状态；旧版树在每个项目标题显示 Workspace，任务不再重复标题。
- 顶部按 T3 默认侧栏提供内联任务搜索、项目筛选、添加 Workspace 和新任务。控件高度 **28 pt**，顶部间距 **8 pt**；项目筛选复用 `line.3.horizontal.decrease`，选中时使用 Workspace 图标。搜索弹层内可按名称筛选项目，设置复用 `gearshape`；右键与 Shift-F10 打开当前项目设置，文字输入保留 I-beam 与输入法。
- Workspace 使用可选择的 SF Symbols 和预设颜色，保存到常驻服务，与名称一起同步至侧栏、任务条目及 Workspace 管理页。编辑提供实时预览、保存和取消；取消不修改数据，修改名称或外观不改变主机目录及 Workspace 背景。选择按钮遵循点击一次 Draw On，并提供颜色名称及选中状态供无障碍使用。
- Mac 任务侧栏固定为最小宽度 **250 pt**，切换页面或调整窗口大小时保持不变。Workspace 名称下方不再显示“新任务 · Workspace”一行，新任务使用当前逻辑项目的代表 Workspace；在项目树中可从指定项目创建。
- Mac 新任务页不显示顶部“项目 / 新任务”标题，引导与输入框整体居中；已有会话的输入框仍固定在底部。
- 非 Git Workspace 的新任务页提示任务将在当前目录执行，并展示目录路径，不显示分支错误。Workspace 信息读取失败时展示目录路径、明确的工作区错误和重试入口；仅确认是 Git 仓库且所选分支失效时提示重新选择分支。
- Workspace 编辑面板与管理页提供红色 `trash` +“删除 Workspace”入口，点击一次 Draw On 并使用小手光标。删除前确认并说明保留目录文件和已有任务；删除仅移除 Workspace 注册，已有任务保留执行目录和 Agent 会话。删除当前 Workspace 后回到全部 Workspace，不再使用其新任务草稿；已删除项目的任务从主列表和顶部计数中移到侧栏左下角的“历史任务”按钮，不再用原目录名创建 Workspace 分组。按钮使用 **16 pt** SF Symbol `archivebox`、固定 **32 × 32 pt** 区域与 **8 pt** 圆角，沿用点击一次 Draw On 和小手光标。点击后向上展开历史任务面板，选择任务后收起面板并在右侧查看，保留原目录继续执行。
- Workspace 筛选与 Mac 侧栏双指横向分页共存。双指左右滑动按筛选器当前顺序在“全部 Workspace”和各个项目间切换，保留跟手位移、相邻页预览、阈值吸附及边界回弹；纵向滚动与普通滚轮不切页，取消及惯性不重复切页。默认列表与旧版树共用手势，切换主机、筛选范围或页面顺序时取消未完成手势；减少动态效果或应用后台时不播放位移过渡。按仓库／仓库与子目录分组，支持逐个 Workspace 覆盖；项目顺序用于筛选器与旧版树。旧版树使用 `chevron.down`／`chevron.right` 展开，保留折叠中的当前任务，默认展示六条并可展开。手动项目排序只改变客户端的项目顺序，不更改任务目录。
- 尚未选择 Workspace 的 Mac 新任务页在引导文字下方直接排列全部已注册 Workspace 卡片，沿用各自的名称、图标和颜色，并显示目录以区分同名项目。卡片按窗口宽度自动换行，与输入框保持相同宽度；引导、卡片和输入框整体居中，项目较多时可纵向滚动。点击卡片仅选择右侧新任务的 Workspace 并聚焦输入框，左侧保持当前筛选范围；在全部 Workspace 中创建任务后也继续显示全部。引导和卡片以 **0.24 秒**淡入淡出切换，输入框位置与随后加载的执行位置选项平滑调整，保留模型、推理强度和各 Workspace 的草稿；减少动态效果或应用处于后台时即时切换。未选择时输入框明确提示先选择上方的 Workspace。卡片使用小手光标，点击图标播放一次 Draw On，悬浮只即时显示静态描边。
- 本地任务聊天输入框不显示“按需确认”或权限模式；权限统一在 Providers 中设置，默认 Auto。任务详情右上角不显示状态徽标或停止按钮。运行、排队或等待确认时，输入框为空显示 **32 × 32 pt** 红色圆形停止按钮，白色 `stop.fill`；有补充文字时切换为发送按钮，运行中的补充使用 `arrow.turn.up.right`。停止请求期间禁用重复点击，切换任务不沿用上一任务的停止状态；停止与补充继续调用常驻服务的原有接口。
- 输入框中的推理强度平时只显示当前档位文字，点击后才在弹出面板中显示横向胶囊分段滑条，不在工具栏中常驻展开。面板只显示当前模型支持的实际强度，不单列“默认”；未指定强度时，直接高亮模型默认对应的档位，打开面板时键盘焦点也定位到该档位。点击切换，拖动时选中块连续跟手、松手吸附档位，支持键盘与 VoiceOver；点击面板外或按 Escape 收起。选中块使用系统原生 Liquid Glass 材质，不自绘玻璃渐变或叠加图标动画。新会话、已有任务共用；执行中禁用。旧系统回退原生 Material，减少透明度时使用实色，减少动态效果或后台时不播放吸附动画。

- 支持托管临时工作区的主机在 Mac／iPhone 项目选择页提供“无项目”卡片，使用灰色 SF Symbol `ellipsis.message`；复用 Workspace 卡片的点击一次 Draw On、小手光标和禁用反馈。选择后显示“开始一个无项目任务”，说明默认目录独立且文件保留；同分支新任务仍显示已选择的目录语义。侧栏、搜索和新任务入口共用“无项目”名称，不翻译普通项目的用户名称。

- “添加 Workspace”复用 `folder.badge.plus`，打开共用的新建项目／已有目录面板；Mac 侧栏、Mac／iPhone 新任务页和 Workspace 管理页使用同一路径。新建项目预览主机目录，首次提交失败时保留项目、说明原因并提供“打开项目”。按钮沿用小手光标和点击反馈。初始化写入的 `assets/icon.svg` 属于用户项目的 README／仓库文件，产品功能图标继续使用 SF Symbols。

- 同一面板增加“克隆仓库”和创建后可选的私有发布。克隆显示实际 Git 阶段及该阶段百分比，不制造总进度或 ETA；取消／重试复用文字按钮与小手光标。未完成克隆不允许发送任务；新任务页及 Workspace 管理页共用状态控件，删除时说明未完成克隆的清理规则，完成后的文件保留。发布结果使用短暂的原生材质通知，关闭与打开仓库复用 `xmark`／`arrow.up.right.square`；依旧只在激活时反馈图标动作。

- 鼠标悬浮在 Task 上时，整条任务显示浅色圆角卡片、细描边与轻微阴影，形成浮起的层次；移出后恢复，已选中的任务仍保留选中背景。悬浮即时反馈，不缩放、不移动布局，也不触发图标动画；按下时减弱阴影，后台与禁用状态不显示悬浮反馈，适配明暗主题和增强对比度。

- 可点击的 Workspace 分组标题与单独工作区顶部编辑入口沿用 Task 的浮起背景、细描边、轻阴影和小手光标；悬浮不触发图标动画，点击仍执行收起／展开或编辑。“全部 Workspace”仍为静态标题。

- 默认侧栏的任务顺序使用独立排序键和创建／恢复锚点，流式更新不跳行。行拖拽的落点仅以静态强调线反馈，菜单上移／下移复用 `arrow.up`／`arrow.down`，沿用单次操作反馈和小手光标，不添加循环动效；原生标题编辑继续保留 I-beam 与输入法。

### 任务处理过程

- “我的任务”的完整 T3 Code 对齐以 [任务对齐清单](t3code-task-parity.md) 为准。侧栏主列表按置顶、活跃、稍后处理、已结束排列，后两组可折叠且保留当前选中任务；归档任务与已删除 Workspace 的记录从历史入口查看。Task 的原生上下文菜单与聊天标题菜单共用重命名、置顶、Settle、Snooze、未读、复制、归档和删除操作；删除正在执行的任务前说明会先停止，不删除项目文件。新增图标继续使用 SF Symbols 和通用小手光标。
- 本地 Agent 的待授权内容及补充问题位于输入框内，不再重复显示聊天卡片。问题逐题展示，保留选项说明、多选、自由输入、前后切换和完成进度；单选后 200ms 前进，最后一题明确提交。普通答案草稿按服务、任务与审批 ID 保存，秘密回答不写入草稿缓存。
- 排队消息显示在输入框上方的紧凑列表，保留图片缩略图、编辑、立即补充、移除及排序手柄。仅从手柄开始拖动；键盘上下移动和手柄菜单提供同等排序能力。运行中默认 Queue，按住 ⌘ / Control 切换 Steer，Agent 尚未就绪时始终排队；发送图标分别为 `text.badge.plus`／`arrow.turn.up.right`，编辑保存为 `checkmark`，恢复为 `play.fill`。偏好从发送按钮菜单保存，图标只随真实操作反馈，不随流式 token 重播。队列编辑保留原来的未发送草稿；停止或服务重启后，列表提供明确的继续入口。
- Codex 每轮（包括续聊）显式请求公开思考摘要；摘要、进度文字和工具输出随事件流更新，短暂输出后的暂停也必须刷新。当前轮次的思考摘要默认展开，可手动收起；历史仍归入可折叠的处理过程。只展示公开摘要，不读取或保存原始推理内容。实现对照 [T3 Code CodexAdapterV2](https://github.com/pingdotgg/t3code/blob/edb21555667dc926bec3f8b2fac41db817b16ae9/apps/server/src/orchestration-v2/Adapters/CodexAdapterV2.ts)。
- 工具正文在展开时按需读取；命令输出只在展开期间独立订阅，以最高 320 pt 的原生可选择文字区域呈现 ANSI 颜色与尾部说明。向上阅读保留滚动位置，回到底部恢复跟随，持续输出不播放图标或布局动效。详情失败的“重新加载输出”沿用 `arrow.clockwise`、单次 Draw On 与启用时小手光标；原生输出文字区域保留 I-beam。输入命令继续复用现有代码块与复制控件，不添加运行状态图标循环。
- 文件改动以目录树、文件数量和绿色／红色增删行数呈现，点击文件打开右侧 Diff；当前工作区与保存的历史补丁明确区分。Diff 支持统一／左右显示、原生文字选择和复制补丁，面板可拖动调整宽度并保存布局。文件、目录、Diff 和面板入口使用 `doc.text`、`folder`、`doc.text.magnifyingglass`、`sidebar.right`；目录折叠使用原生 chevron，不随输出重复播放。
- 完整轮次在最终回复后显示一张整轮净改动卡，逐工具补丁保留在工作日志；面板可选择当前改动、整轮检查点 Diff 或旧工具补丁，并标明来源。卡片和面板复用原有文件树、统计、折叠与 Diff 图标，检查点恢复或快照刷新不重播点击动效；没有完整检查点时显示原因，不把当前文件冒充历史内容。
- 已落入执行轮次的原始用户消息使用 `arrow.uturn.backward` 提供“从这里编辑”，沿用单次 Draw On 和小手光标。确认面板区分“同时恢复文件”和“回退并保留改动”；共享目录仅能保留文件。任务、Git 或回退执行期间禁用重复操作。回退后原请求和附件返回输入框，旧草稿可恢复；异常状态提供原生历史核对、查看当前改动、明确重试恢复或保留当前文件，不自动重播未确认的外部操作。回退与恢复进度不计入 Agent 的 Working 用时。
- 较早请求的重试执行也在回退范围内时，确认面板补充说明保留原请求、回退其后续回复和处理记录。保留的请求不再显示已排除执行的整轮改动卡、历史 Diff 或分叉入口；本项沿用现有文字和控件，不新增图标或动效。
- 已结束回复和方案的“从此回复分叉”使用 `arrow.triangle.branch`；任务中的来源链接使用同一符号，打开原任务时保留当前草稿。分叉进度与异常在任务内及侧栏独立呈现，不计入 Agent 的 Working 时间；控件遵循启用时小手光标和点击单次 Draw On，不在保存历史或流式刷新时重播。未知回执显示核对或明确建立新会话的入口，不通过重复点击悄悄创建另一份原生分叉。
- 历史时间线的“加载更早的记录”使用 `clock.arrow.circlepath`；加载时保留当前滚动目标、工作组折叠状态和输入草稿，不把新页当作新回复自动滚到末尾。控件继续遵循启用时小手光标和点击单次 Draw On，不用旋转符号模拟分页状态，也不因旧历史进入视图而重播完成动效。
- 普通任务历史以完整轮次载入，首次显示最近 10 个用户轮次，向前通常增加 20 轮；工具日志随轮次一起进入时间线。继续复用同一个“加载更早的记录”入口，较早的控制元数据不提前生成改动卡片。断线补页和消息回执更新不抢输入焦点、不播放点击动效、不把正在阅读的旧页拉到末尾。
- 侧栏使用轻量任务摘要，选中任务才订阅正文。重连保留当前阅读窗口和草稿，恢复缓存中的历史不会播放新消息或点击动效；新的回退投影不显示旧页。首次读取沿用现有静态加载占位；确认删除后显示任务不存在，不用持续旋转图标掩盖缺失。没有新增产品图标，文字与现有控件继续沿用原有交互样式。
- 侧栏双击任务标题或菜单重命名时原位显示原生单行编辑器，标题栏菜单也原位编辑；选择全部标题，Enter／失焦保存、Escape 取消。编辑区域保留 I-beam、原生选择、撤销和输入法组词；编辑时不播放标题滚动或按钮动效。其余任务行继续沿用小手光标与共享行样式。
- 重新生成任务标题在上述两个菜单中复用 `arrow.clockwise`、启用时小手光标和点击单次 Draw On。生成期间保留旧标题并以 55% 不透明度及悬浮／无障碍文字提示，菜单项禁用；标题编辑器始终清晰，手动保存即使旧生成失效。不添加循环旋转或自动抢焦点，完成后的标题替换不触发点击动画。
- “文字生成”设置及 Workspace 编辑中的同名入口使用 `text.bubble`，点击单次 Draw On。模型弹层复用品牌图标、搜索／收藏和当前窗口的 ⌘1–9 选择；主机／Workspace 范围、推理档位、恢复继承与重载按钮沿用启用时小手光标。同步状态用静态文字，失败重载用 `arrow.clockwise` 的点击反馈；切换范围或接收保存结果不重播图标，不主动聚焦字段。
- 任务关系入口复用 `arrow.triangle.branch`，父任务行使用 `arrow.turn.up.left`，继续展开使用 `plus`。父任务优先、分叉按创建时间排列，首批 6 项、每次增加 12 项；来源不存在时显示保存的名称及不可用状态，不提供错误跳转。入口和展开按钮沿用点击单次 Draw On 与启用时小手光标，关系或执行状态更新不重播。
- ⌘1–9 跳转当前可见列表的前九项，⌘⇧[／⌘⇧] 按列表顺序导航且不循环；模型面板打开时数字键选择过滤后的模型。使用当前窗口的原生菜单和作用域，切换任务、恢复草稿或更新快捷键目标均不播放新增动效；实际键盘、输入法和弹层行为由用户检查。
- 搜索任务入口使用 `magnifyingglass`，放在侧栏底部右侧及任务菜单，手机列表使用同一入口；侧栏不增加常驻输入框。弹层使用原生搜索字段和 I-beam，上下键选择结果、Enter 打开，Escape 先清空再关闭，组词期间不抢按键。结果沿用共享任务行的小手光标和选中样式，摘要以用户／Agent 文字标明来源、匹配处加粗；不播放流式动效。明确失败后的重新搜索复用 `arrow.clockwise`、单次 Draw On 和启用时小手光标，不用旋转图标代表查询进度。
- 工作区准备失败在原用户消息后显示 `exclamationmark.circle`、错误原因与 `arrow.counterclockwise` 重试按钮。准备中使用静态 `circle.dashed` 和文字，不冒充 Agent Working 用时；旧错误在新尝试受理后收起。重试沿用启用时小手光标和点击单次 Draw On，不添加旋转循环；流式快照和历史重现不重播点击动效。
- 任务终端由标题栏 `terminal` 或 ⌘J 展开，位于对话输入框下方；`plus` 新建标签、`rectangle.split.2x1` 拆分、`magnifyingglass` 搜索、`ellipsis` 提供重命名／字体／清空／重启，`chevron.down` 仅收起面板。每个终端的 `xmark` 才表示关闭，存在子进程时需明确确认停止；收起、切换任务和关闭客户端均不终止主机进程。控件复用单次 Draw On 和小手光标，终端文字区域保留原生文字选择、键盘与文本光标；终端持续输出不重复播放图标动效。面板高度、标签分组与选择按各自作用域保存，明暗主题使用原生终端颜色。
- 上下文入口使用 `at`，文件、目录、代码片段与终端选区分别沿用 `doc.text`、`folder`、`chevron.left.forwardslash.chevron.right`、`terminal`。输入框和消息内的原生富文本标签可整项选择、删除、撤销与点击预览；标签图标是静态 SF Symbol 附件，不声称支持系统符号动画。搜索建议锚定输入光标，使用上下键选择、Enter 确认和 Escape 关闭，中文输入法组字期间不抢键；弹层保留编辑焦点。原生文字区域维持 I-beam，可点击标签与按钮显示小手，工具栏和预览按钮沿用通用单次 Draw On。

### Mac 任务输入框

- 新任务和已有本地 Agent 任务的输入框默认显示完整尺寸，进入页面或切换已有任务时恢复完整尺寸，不自动聚焦编辑器；新任务页主动选择 Workspace 卡片后仍聚焦编辑器。
- 只有对话内容超过可视聊天区域，且在聊天区手动向上滚动查看历史时，才收起输入框并移除编辑焦点；短对话和弹性回弹不触发收起。收起后为 **44 pt** 高的空白半透明横条，不显示模型、占位文字、草稿、分支、推理强度、错误提示或发送按钮。点击整个横条或通过键盘激活后聚焦编辑器，恢复完整输入框；鼠标悬浮不触发展开。
- 收起时保留草稿及模型设置；向下滚到对话底部或通过“回到最新”返回底部时，以相同过渡自动恢复完整尺寸，不自动聚焦编辑器。输入框收起造成的底部留白变化不触发恢复。展开后操作模型、分支与推理强度面板不会收起输入框。
- macOS 26 及以上的收起与展开状态共用一块原生 **Liquid Glass** 表面，使用 `glassEffect` 和稳定的玻璃标识，不自绘玻璃渐变、边缘高光或折射；旧系统使用原生 Material。输入框保留完整编辑内容的自然布局，外框在 **44 pt** 与实测完整高度之间以 **0.36 秒**平滑动画连续变形，内容同时淡入／淡出，不在零高度与自动高度间跳变。
- 已有任务的输入框浮在聊天内容上方。为最新回复预留输入框的实际高度，查看历史时允许文字从横条后面经过；流式更新、程序滚动与输入框高度变化不触发收起。
- “减少透明度”或增强对比度时使用实色背景；“减少动态效果”或应用在后台时不播放尺寸过渡。空白输入入口、模型与完整工具栏沿用通用小手光标及键盘／无障碍行为，iOS 保留现有输入框。

### 通用兼容规则

- 任务输入框上方的后台工作面板复用 `square.stack`，命令、监视器、子 Agent 分别使用 `terminal`、`waveform.path`、`person.2`。逐项停止使用 `stop`，沿用启用时小手光标与点击单次反馈；后台输出复用原生终端文字选择与 I-beam，输出刷新不播放图标动效。等待后台任务与真实授权请求分别呈现，不播放持续运行的状态动画。
- 后台工作面板中的整组停止复用 `stop`，不确定回执后的显式重新核对使用 `arrow.clockwise`。等待停止时禁用重复操作并显示静态文字；整组停止不计入模型 Working。账号、服务或执行会话切换后，旧回执不得改写当前控件；继续使用共用小手光标与点击单次 Draw On。
- 原生子 Agent 的启动行、关系入口内的子任务和只读状态栏使用 `person.2`；进入对话的方向提示使用 `chevron.right`，返回父任务使用 `arrow.turn.up.left`。不使用持续旋转表示运行，时间以静态文字更新；复用通用按钮样式、小手光标和点击单次 Draw On，历史状态不因打开重播。

- 遵循系统“减少动态效果”设置，启用时保留清晰的静态图标和选中状态。
- 应用处于后台时不触发交互动画；返回前台不补播已发生的反馈。
- 新符号和动效必须检查 SDK 与系统版本，并为项目最低支持版本提供降级。旧系统缺少符号时使用语义相近的 SF Symbol。
- Draw On 不可用时保留静态 SF Symbol，不回退到其他类型的图标动效。降级同样遵循无障碍设置。
- 设置齿轮的原生 Rotate 需要 macOS 15 / iOS 18 或以上；不支持时保留静态图标，同样遵循减少动态效果与后台停止规则。
- 平台控件无法呈现某种动效时，明确说明限制，不能把静态图标报告为已经验证的动画。
- 系统管理的原生标签栏保留系统图标呈现；不能直接套用自定义图标转场，也不把它计为已完成 Draw On 验证。

## 验证与维护

- UI 改动完成后只做差异检查、编译并打开当前工作区的应用，效果由用户亲自验收。默认不采集窗口、不截图、不读取无障碍树，也不执行自动界面复核；仅在用户明确要求时进行。
- 代码层面保留触发方式、单次播放、动画结束后的完整图标、减少动态效果和后台停止约束；历史状态不应在打开或刷新时重播。
- 编译通过不等于界面效果已验证，交付时如实说明完成的检查。
- 本文保存具体偏好、符号与动效约定，不复制实现源码；项目 `AGENTS.md` 保留关键规则与本文链接。
