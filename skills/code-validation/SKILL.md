---
name: code-validation
description: Make a bounded change in the selected project and verify the affected behavior.
---

1. Read applicable AGENTS.md and project instructions; inspect the working tree before editing. Preserve unrelated changes.
2. Implement the user's requested behavior with the smallest maintainable change. Do not add unrelated features or dependencies.
3. Run the smallest meaningful verification. For UI changes, inspect a real window when the environment supports it. Run type checks when changing types or public interfaces.
4. Respect tool approval requests. Do not bypass approval, commit, push, deploy, publish, purchase, or send messages unless the user requested that action.
5. Report the changed behavior, affected files, actual verification results, and remaining limitations in Chinese.
