# Friday 0.1.0 Beta 2

本版包含 Beta 1 发布后合并到主线的全部改动。macOS 安装包适用于 Apple Silicon 和 macOS 14 或以上，内置原生客户端、Node 和 Pi Durable 常驻服务。

- 新建本地任务时可以选择当前工作区或创建独立 Worktree，并选择起始分支；已有任务显示实际执行目录和分支，支持在工作区空闲时切换分支。
- 工作区与分支操作由持久任务处理；遇到未提交改动、活动任务或结果不确定的中断时会阻止重复操作。软件更新也会等待工作区操作结束。
- 优化任务侧栏与新任务入口：按工作区分组，压缩任务行，明确展示任务执行位置，改善任务切换。
- 本地任务展示执行活动摘要和操作详情，改善对话记录与审批信息的阅读体验。
- 任务输入框采用自适应 Liquid Glass 样式（支持的系统上），向上浏览记录时收起，回到底部时恢复；模型和推理强度控件更紧凑。
- 统一 Worktree 图标；macOS 开发构建在应用名、窗口标题和 Bundle Identifier 中区分工作区，方便多个工作区并行使用。发布安装包仍为 Friday。
- 源码同步包含 FridayPersonal 的本机签名配置支持，便于重新编译并覆盖安装已有 iPhone 客户端。

## 安装与更新

首次安装：下载 DMG，将 Friday 拖入 Applications 后打开，并允许 Friday 在系统登录项中后台运行。已安装 Beta 1：在 Friday 菜单中选择「检查更新…」。更新前请完成或停止正在执行的任务。

沿用原有数据目录、凭据和设备配对信息。关闭客户端窗口不会停止后台服务；可在「软件更新与后台服务」窗口中停止服务，数据会保留。

这是个人测试版，使用 ad-hoc 代码签名和 Ed25519 更新包签名，尚未使用 Developer ID 签名或经过 Apple 公证。若 macOS 阻止首次打开，请在「系统设置 → 隐私与安全性」中允许这次打开。

发布附件只包含 macOS 软件。iPhone 客户端的界面更新需要使用 Xcode 重新编译安装；Codex、Claude 等外部编码工具仍需在 Mac 上单独安装和登录。
