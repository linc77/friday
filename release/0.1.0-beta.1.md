# Friday 0.1.0 Beta 1

Friday 的首个 macOS 独立安装测试版，适用于 Apple Silicon 和 macOS 14 或以上。

- 原生 SwiftUI 客户端、Node 24.21.0、Pi Durable 常驻服务和生产依赖一起打包，无需准备开发环境。
- 通过 macOS 登录项管理后台服务，关闭窗口后任务仍由服务处理。
- 菜单「Friday → 检查更新」使用 Sparkle 验证并安装后续版本。
- 更新前检查活动任务、阻止新写入、停止服务并备份数据库；任务尚未完成时暂缓安装。
- 保留现有数据目录、主机凭据、记忆和设备配对信息。

## 安装

下载 DMG，将 Friday 拖入 Applications，然后从应用程序目录打开，允许 Friday 在系统登录项中后台运行。

这是个人测试版，使用 ad-hoc 代码签名和 Ed25519 更新包签名，**尚未使用 Developer ID 签名或经过 Apple 公证**。如果 macOS 阻止首次打开，请在「系统设置 → 隐私与安全性」中允许这次打开。不要关闭系统安全保护。

只包含 macOS 软件；iPhone 客户端继续使用已有安装。Codex、Claude 等外部编码工具仍需在主机上单独安装和登录。服务需要 Mac 保持在线，系统休眠或关机时不能执行任务。

关闭 App 不会停止服务；在「软件更新与后台服务」窗口中可以停止它。卸载前先停止服务，用户数据会保留。
