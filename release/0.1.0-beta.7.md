# Friday 0.1.0 Beta 7

<!-- friday-build: 7 -->

## 改进

- 精简 Mac 任务工具栏，将文件与终端收进右侧可折叠面板，移除重复箭头、网页和脚本快捷入口。
- 消息操作改为悬浮显示，回复下方的复制与分叉图标并排排列；附件上传移至输入工具栏最左侧。
- 侧栏统一为置顶与最近，恢复可点击的 Workspace 分页圆点，并提供直接归档入口；移除 Workspace 后仍保留相关对话。
- 默认关闭闲置自动结束跟进，保留用户已有设置；会话清理不再决定 Mac 对话列表的可见性。
- 移除计划模式、模型选项菜单及 Mac 新任务页的“从 PR／MR 开始”入口，简化任务创建流程。
- DMG 增加原生安装器，显示安装进度并支持安装完成后打开应用。

## 安装与更新

适用于 Apple Silicon、macOS 14 或以上。更新前请完成或停止正在执行的任务；更新保留原有数据、密钥和设备配对。

这是使用 ad-hoc 代码签名和 Ed25519 更新包签名的个人测试版，尚未使用 Developer ID 签名或经过 Apple 公证。iPhone 客户端需要另行编译安装。
