# Friday 0.1.0 Beta 4

本版重点修复任务回复正文空白，并保留原有的双指滑动工作区切换；同时包含这一阶段已实现的任务模块改进。安装包适用于 Apple Silicon 和 macOS 14 或以上，内置原生客户端、Node 和 Pi Durable 常驻服务。

- 修复 macOS 回复正文的原生文字组件初始化错误：模型已有回复时，界面不再只剩复制和分叉按钮。补充实际原生文字存储、排版、流式更新和引用选择的回归检查。
- 恢复侧栏双指左右切换工作区、跟手移动、相邻页预览和边界回弹，与项目筛选、仓库分组和旧版项目树共存。
- 完善任务队列、运行中补充、审批与问题选择、归档恢复、稍后提醒、历史分页、搜索，以及原生会话分叉和回退的已支持路径。
- 增强消息、代码、图表与媒体呈现，提供文件浏览编辑、自动保存、Diff 批注、集成终端和任务网页面板。
- 完善 Worktree 准备、项目创建与克隆、项目脚本，以及 Git 和 PR／MR 工作流。主机网页模式需要已安装的 Chrome／Chromium，或由主机配置浏览器路径。
- 新增 Pi、Grok、Cursor、Muse、OpenCode、Antigravity 与 ACP Registry 的基础任务接入，按各工具真实能力提供模型发现、会话续接、输出与停止等功能。新接入默认关闭，工具准备与登录由用户显式启动；外部工具仍需对应账号或安装环境。

## 安装与更新

首次安装：下载 DMG，将 Friday 拖入 Applications 后打开，并允许 Friday 在系统登录项中后台运行。已安装旧版：在 Friday 菜单中选择「检查更新…」。更新前请完成或停止正在执行的任务。

沿用原有数据目录、凭据和设备配对信息。关闭客户端窗口不会停止后台服务；可在「软件更新与后台服务」窗口中停止服务，数据会保留。

这是个人测试版，使用 ad-hoc 代码签名和 Ed25519 更新包签名，尚未使用 Developer ID 签名或经过 Apple 公证。若 macOS 阻止首次打开，请在「系统设置 → 隐私与安全性」中允许这次打开。

发布附件只包含 macOS 软件，iPhone 客户端需要另行编译安装。完整 T3 任务模块对齐仍在进行，多实例、完整模型选项及部分新驱动的历史／后台／额度功能尚未全部接通；新增驱动的真实账号与跨端原生交互也仍需逐项验收。本次发布不代表完整 1:1 已完成。
