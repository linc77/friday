# Friday 0.1.0 Beta 5

本版整合 Beta 4 之后的任务执行、上下文交接和原生交互改进。适用于 Apple Silicon 和 macOS 14 或以上，内置原生客户端、Node 和 Pi Durable 常驻服务。

- 双指工作区分页改用 AppKit 图层驱动跟手位移与吸附，减少逐帧 SwiftUI 重排；继续保留项目筛选和相邻页预览。
- 修复连续原生后台回复的登记和持久化收尾顺序，避免旧回复覆盖新回复的当前结果。
- 完善 Provider 实例与账号隔离、模型选项、独立文字生成、原生额度，以及已声明支持的历史与后台会话能力。
- 支持普通文件选择、粘贴、拖入及认证下载；附件保存不可变内容，排队、分叉和回退沿用同一引用。
- 同一任务空闲时可切换 Agent 或 Provider 实例，保留来源历史；补上合并回原任务、断开会话和首次发送时创建普通原生分叉。
- 新增应用托管的跨 Agent 子任务，支持共享目录或本地提交 Worktree、等待或异步回传、停止、问题回答及增量读取；新增原生关系入口和返回父任务操作。

## 更新

沿用原有数据目录、凭据和设备配对信息。更新前会确认没有活动任务，停止自有后台服务并备份数据库。关闭客户端窗口仍不会停止后台服务。

这是使用 ad-hoc 代码签名和 Ed25519 更新包签名的个人测试版，尚未使用 Developer ID 签名或经过 Apple 公证。首次安装如被 macOS 阻止，可在系统设置的隐私与安全性中允许打开。

本版不代表完整 T3 1:1 已完成。完整线程与调度工具、私密输入、子任务独立权限，以及真实供应商账号和原生交互仍有待完成或验收。iPhone 客户端需要另行编译安装。
