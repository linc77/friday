# Friday 0.1.0 Beta 11

<!-- friday-build: 11 -->

## 新功能

- 外观设置增加正文字体、字号、代码字体、代码配色和对话宽度选项。
- Friday 对话头像支持分别调整球体、眼睛和领结颜色。

## 改进

- 优化模块与任务切换，减少无关数据更新、重复排版和历史记录计算对当前界面的影响。
- 输入框收放时保持会话滚动范围稳定，保留上翻收起、点击展开和回到底部恢复的交互。
- 统一对话气泡、输入框、Markdown 排版及 Midnight 主题的面板样式，精简文件改动卡片。
- 功能图标默认保持静态，左侧栏仅保留想法与设置入口的单次点击动效。
- 统一 Claude 的会话启动、能力检测和输入处理，改善不同入口的行为一致性。

## 修复

- 修复右侧工具面板拉宽时出现白色竖条和绘制残留的问题。
- 修正 Task 模块切换时侧栏小手光标的原生交互区域。
- 修复思考记录与工具记录只有部分标题区域能够点击展开的问题。

## 安装与更新

本次提供 Apple Silicon macOS 安装包，现有用户可通过「检查更新」获取。

此版本为个人测试版，尚未经过 Developer ID 签名和 Apple 公证。
