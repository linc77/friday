# Friday 0.1.0 Beta 8

<!-- friday-build: 8 -->

## 改进

- 升级 Pi Durable 至 1.5.0，适配会话历史、工具结果与存储接口，保留旧任务数据的迁移和搜索兼容。
- Agent 入口精简为 Codex、Claude 和 Pi；历史任务仍可查看，已移除的执行器不会被静默切换或重新执行。
- Mac 侧栏增加新版提示入口，便于发现和打开更新公告。
- 远程连接配置改为固定 HTTPS 隧道方案，精简主机连接设置并收起已配对设备的重复表单。

## 修复

- 修复部分安装包升级后重新打开即崩溃的问题：应用现在从安装包内正确加载界面资源，不再依赖构建机上的目录。
- 修复 iPhone 切换页面时可能出现的对话堆栈溢出；底部导航保留在首页，滚动时可收起。

## 安装与更新

适用于 Apple Silicon、macOS 14 或以上。更新前请完成或停止正在执行的任务；更新保留原有数据、密钥和设备配对。

如果 beta.7 已无法打开，请下载本版本 DMG 重新安装；无法从崩溃的客户端打开应用内更新。升级包含 Pi Durable 数据库迁移，请保留更新前备份，不要直接用旧版程序打开升级后的数据库。

这是使用 ad-hoc 代码签名和 Ed25519 更新包签名的个人测试版，尚未使用 Developer ID 签名或经过 Apple 公证。iPhone 修复已包含在源码中，客户端仍需另行编译安装；macOS 自动更新不会更新 iPhone 应用。
