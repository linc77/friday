# Friday 0.1.0 Beta 6

<!-- friday-build: 6 -->

## 新功能

- Friday 主会话支持自定义 OpenAI 兼容模型供应商，可填写名称、Base URL 和 API Key，获取模型列表后选择使用的模型。
- 新增应用内更新公告，按新功能、改进和修复分类展示，并可离线回看历史版本。

## 改进

- 模型列表支持分页获取、去重和搜索，保存前测试所选模型；验证失败保留原有连接。
- 供应商、模型与密钥保存在主机，重启后恢复；现有 DeepSeek 配置继续兼容，设备配对与原有数据保持不变。

## 修复

- 修复后台服务使用 Background 调度时可能出现的冷启动严重延迟，保持客户端请求可及时响应。
- 更换供应商 URL 后必须重新填写密钥，避免把原供应商的密钥发送到新地址。

## 安装与更新

适用于 Apple Silicon、macOS 14 或以上。更新前请完成或停止正在执行的任务；更新过程会保留原有数据、密钥和设备配对，并备份数据库。

主会话自定义供应商需要提供 OpenAI 兼容的模型列表与 Chat Completions 接口，请选择支持工具调用的对话模型。其他原生 API 协议需要通过兼容网关接入。

这是使用 ad-hoc 代码签名和 Ed25519 更新包签名的个人测试版，尚未使用 Developer ID 签名或经过 Apple 公证。iPhone 客户端需要另行编译安装。
