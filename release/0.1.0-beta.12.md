# Friday 0.1.0 Beta 12

<!-- friday-build: 12 -->

## 新功能

- 任务会话支持交互 HTML 预览，可直接查看 Agent 生成的页面、图表和交互内容，并展开或重新加载。
- 增加个人工作区设置，可指定 Friday 存放个人文件的主机目录。

## 改进

- 统一 Friday 主目录与后台服务路径，兼容已有数据目录。
- 精简移动端笔记编辑界面，将常用操作移至底部工具栏，并优化照片选择与导入体验。

## 修复

- 修复笔记同步版本保留与失败上传处理，避免单条失败阻塞其他笔记同步，并将错误提示限定到相关笔记。
- 恢复 Mac 窗口顶部留白区域的拖动操作。

## 安装与更新

本次提供 Apple Silicon macOS 安装包，现有用户可通过「检查更新」获取。移动端改动已同步至源码，需重新构建 iOS 客户端。

此版本为个人测试版，尚未经过 Developer ID 签名和 Apple 公证。
