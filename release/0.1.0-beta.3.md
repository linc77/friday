# Friday 0.1.0 Beta 3

本版包含 Beta 2 发布后合并到主线的全部改动。macOS 安装包适用于 Apple Silicon 和 macOS 14 或以上，内置原生客户端、Node 和 Pi Durable 常驻服务。

- Codex 和 Claude 本地任务支持图片附件，可在新建任务或补充要求时选择、粘贴或拖入图片，并在对话记录中查看。
- 任务输入框改用原生文本编辑器，改善中文输入、文本选择、撤销和快捷键体验；支持保存新任务及会话草稿，发送失败时保留内容和附件。
- 补充要求会先持久化再发送；连接中断或发送结果不确定时显示提示，避免自动重复发送。
- 简化 Friday 主对话界面，移除重复的执行详情、状态和成果卡片，让对话内容更集中。
- Workspace 支持删除，保留目录文件、已有任务和 Agent 会话；移除的 Workspace 关联任务可从「历史任务」入口查看并继续。
- 改善任务侧栏的 Workspace 分组、历史任务入口和分页导航，并为不可用分支、未首次提交等执行位置问题提供明确提示。

## 安装与更新

首次安装：下载 DMG，将 Friday 拖入 Applications 后打开，并允许 Friday 在系统登录项中后台运行。已安装旧版：在 Friday 菜单中选择「检查更新…」。更新前请完成或停止正在执行的任务。

沿用原有数据目录、凭据和设备配对信息。关闭客户端窗口不会停止后台服务；可在「软件更新与后台服务」窗口中停止服务，数据会保留。

这是个人测试版，使用 ad-hoc 代码签名和 Ed25519 更新包签名，尚未使用 Developer ID 签名或经过 Apple 公证。若 macOS 阻止首次打开，请在「系统设置 → 隐私与安全性」中允许这次打开。

发布附件只包含 macOS 软件。iPhone 客户端的界面更新需要使用 Xcode 重新编译安装；Codex、Claude 等外部编码工具仍需在 Mac 上单独安装和登录。
